# IRStore24 — Under Construction

Phase 0 landing page for IRStore24.

## Local development

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Docker

```bash
docker compose up -d --build
```

## Before deploying

Edit Telegram and Discord links inside:

```text
app/page.tsx
```

Replace:

```text
YOUR_TELEGRAM_USERNAME
YOUR_DISCORD_INVITE
```

with your real values.
